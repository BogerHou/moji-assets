## 内容更新

在main分支编辑gallery.json中的标题、标签、顺序、enabled以及presentation分类词表。新图片先补全base-catalog.json的来源、版权状态和资源信息，使用新的不可变assets路径。未知字段、缺图、图片哈希改变或非法标签会阻止发布。

提交后由Actions发布到published分支；小程序通过固定的channels/gallery-v2.json读取新目录。每次发布同时维护release.json兼容入口，二者在同一Git提交内更新。CDN分支缓存可能延迟后续内容更新，发布成功不保证即时送达。

临时隐藏使用enabled:false；永久撤下加入withdrawnIds，旧ID不可复用。不要直接编辑或强推published分支，不要覆盖已发布图片路径。回滚运营配置必须作为新提交，累计撤下记录仍生效。

新增图片先复查完整原图、背景和拼图，优先手臂、腿、手、脚局部构图，排除露胸、大面积裸背/胸腹、腰胯近景及裸身人物手稿。来源核验、图像尺度检查、运营展示决定分别记录，不将其写成权利人授权。
